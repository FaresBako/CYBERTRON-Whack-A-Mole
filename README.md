Game explanation: Basically you have five LEDs that runs randomly in a pace that controlled with the potentiometer, after a certain time from the LED times run, it will turn off and the idea of the game is to press the LED while its on before it goes off, if you missed it three times you will lose and all LEDs will run as an indicator for starting a new game.



Problems faced: one of the annoying problems is the connection and how i need to distribute all the components and comprehend them together with the code, as i used an extra breadboard to place the buttons then connect them with a jumper wire + also the code was complex i needed to do three functions codes at a time one for buttons, LEDs and the potentiometer then combining them
